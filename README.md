## Descripción

Chunche es un sistema robótico diseñado para apoyar a especialistas en la conservación de obras patrimoniales. Utiliza visión computacional, automatización y manipulación de precisión para asistir en tareas de inspección, documentación y conservación preventiva.

El proyecto busca reducir los tiempos de análisis y documentación de piezas culturales, permitiendo que más obras puedan mantenerse accesibles para la investigación y exhibición.

---

## Características principales

* Brazo robótico de precisión.
* Sistema de visión computacional.
* Cámara Raspberry Pi Camera V1.3.
* Procesamiento mediante Raspberry Pi 5.
* Módulo de iluminación para análisis visual.
* Estaciones especializadas para pinturas, esculturas y limpieza.
* Operación segura bajo supervisión humana.

---

## Flujo de operación

1. Ingreso de la obra.
2. Captura de imágenes.
3. Análisis visual automatizado.
4. Identificación de características relevantes.
5. Limpieza superficial asistida.
6. Documentación digital del proceso.

## Objetivo

Desarrollar una herramienta robótica que apoye a los especialistas en conservación patrimonial mediante procesos automatizados de inspección, documentación y asistencia técnica, manteniendo siempre la supervisión humana y la seguridad de las obras.
